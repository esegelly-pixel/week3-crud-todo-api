# Week 3 CRUD Todo API

## Endpoints
- GET `/`
- GET `/todos`
- GET `/todos/active`
- GET `/todos/completed`
- GET `/todos/:id`
- POST `/todos`
- PATCH `/todos/:id`
- DELETE `/todos/:id`

## Render
Create a Render Web Service from this repository.

Build Command:
`npm install`

Start Command:
`npm start`

Render provides the `PORT` environment variable; the app listens on `0.0.0.0`.

After deployment, the API URL will look like:
`https://week3-crud-todo-api.onrender.com`

Test:
`https://YOUR-URL.onrender.com/todos`
